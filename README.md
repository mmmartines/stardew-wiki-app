# Stardew Wiki PT (Android)

App não oficial para consultar a Stardew Valley Wiki em português (pt.stardewvalleywiki.com) pelo celular.

## O que tem
- Menu inicial com ~35 seções (Aldeões, Culturas, Peixes, Pacotes, Festivais, Minas…)
- Busca instantânea por título + busca no texto completo
- Páginas com layout para celular, tabelas roláveis, modo escuro
- Menu "Seções" para pular direto a uma parte da página e "Buscar nesta página"
- Links internos abrem dentro do app; categorias viram listas navegáveis
- Todas as páginas (A–Z) e todas as categorias da wiki
- Favoritos, histórico e leitura offline das páginas já abertas
- Tamanho do texto ajustável

## Gerar o APK pelo GitHub (dá para fazer só pelo celular)
1. Crie um repositório no GitHub e envie estes arquivos (mantendo as pastas).
2. A aba **Actions** compila sozinha ("Gerar APK"). Leva ~5 min.
3. Abra a execução concluída → **Artifacts** → baixe `StardewWikiPT-apk`, descompacte e instale o `.apk`
   (o Android vai pedir para permitir "instalar apps desconhecidos").

## Gerar no computador
Abra a pasta no Android Studio (Hedgehog ou mais novo) e clique em Run. Requer JDK 17.
